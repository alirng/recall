**Agents can hand work to any chat.** `message_chat` reaches any chat on this Mac, in any project. An agent finds the chat with `search_chats` or `recent_chats` and sends up to 4,000 characters, with a `who` line saying who it is. The message arrives quoted and marked as from another agent, and the chat that gets it treats it as a request from a colleague. A closed Claude Code chat or an idle Codex thread is woken to read it, resumed headlessly with anything that needs approval refused (`[messaging] inherit_permissions = true` keeps your own settings). An open Claude Code chat is woken only with `[messaging] wake_open_sessions = true`, because that turn runs with the chat's own permissions, and Cursor reads messages on its next turn. Nothing stays running, a message counts as delivered only once it is in the chat's transcript, and `wake = false` turns waking off. See docs/coordination.md.
