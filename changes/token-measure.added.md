**Agent evals report recall's own tokens, cost per solved task and gains and breaks.** Every agent eval run (qa_v2, the SWE-ContextBench agent, MemoryCode) now adds, per task, the weighted cost of the agent's reported usage (one table of price ratios in `evals_tokens.py`), recall's own tokens counted once (tool definitions, server instructions, a hook block, each tool's results) and `solved`; the summary adds cost per solved task. `recall eval tokens RUN...` re-scores stored runs into a copy, `recall eval compare` compares the new columns with paired intervals and counts the cases memory helped, broke or left alone against how many flip when an arm is simply rerun, and `--no-recall` runs qa_v2 and the SWE-ContextBench agent without recall's MCP server as the baseline. `tokens_in` is unchanged.
