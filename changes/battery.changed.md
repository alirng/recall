**recall waits for power on battery.** `recall dream` defers itself when it starts on battery outside a terminal, the nightly run included (launchd runs a missed night when the Mac wakes), and the first tool call or session start on power runs it in the background. Tool calls start no background indexing or embedding on battery, and the jobs recall starts in the background run at low priority. `recall status` and `recall doctor` say when a run was deferred. `recall dream --on-battery run` runs one anyway, and `on_battery = "run"` under `[power]` in config.toml lets everything run on battery.
