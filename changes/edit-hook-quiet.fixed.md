**The edit hook stops agents only for a clash that is happening now.** It used to stop or warn whenever another chat had open changes to the file and had written anything in the last 15 minutes, so an orchestrator's sub-sessions, a chat that had finished, and a branch merged days ago all raised it. Now the other chat must have written in the last 5 minutes and edited that file in the last 15 (30 and 60 across branches); anything older is quiet, and a chat whose last message is outside the hook's window is ignored. The four `[coordination]` rules are unchanged.
