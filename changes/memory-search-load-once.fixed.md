**memory_search parses no note when the notes have not changed.** It used to load every note a second time to rank notes by meaning; it now takes their words from the notes index, which holds the same text. With 733 notes and embeddings on, such a search takes about 35 ms through the MCP server, against about 530 ms in 0.4.2. When other code rebuilt the notes tables, such as an agent's server still running an older release, the next search builds them again under its own layout.
