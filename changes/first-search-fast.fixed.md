**The Mac app's first search after a pause answers at once again.** Since 0.6.1, `recall api`'s search waited up to a second for the scan for new chats, so on a library of thousands of chats the first search after a quiet minute took about 1.5 s. It now starts the same scan and answers from the index as it stands, and the chats the scan adds arrive as a `chats` change on `/v1/events`. Agents' `search_chats` still waits for the scan as before. `recall api --socket` also takes a bare file name now instead of failing.
