**Hooks work when recall is installed under a path with a space.** `recall install` wrote the hook command unquoted, so from a folder such as `~/Library/Application Support/pipx` every hook failed in the agent's shell, a second install added the entries again, and `recall uninstall` left them behind. The path is now quoted, and the next `recall install` (or autopilot) repairs the entries an earlier release wrote.
