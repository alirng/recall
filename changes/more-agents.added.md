**More coding agents: compatible support.** recall now indexes the chat history of OpenCode, Kilo Code, Antigravity, Gemini CLI, Qwen Code, Pi and its forks, GitHub Copilot CLI, Factory Droid, Cline, Roo Code, Goose, Crush and more (the list and each agent's support level are in `docs/agents.md`), so `search_chats` and `read_chat` find those chats under the agent's name and folder. `recall install` also registers recall's MCP server in the config file each of these agents documents, with a backup first and a restore on `recall uninstall`. Compatible means history and MCP only: no session-start hooks, briefs or notes for these agents, and their chats stay out of the nightly notes unless you set `mine = true` for the agent under `[roots.<name>]`. Adding these sources changes the chat schema, so the chat tables rebuild from the agents' files once after the upgrade (about three minutes on a 4,600-chat index with a large Cursor history; an index with nothing new takes about the same 0.3 seconds as before).
