**Shorter tool results.** An agent pays for every tool result again on each later turn, so three results are smaller. `search_chats` answers in text only (Claude Code showed the model a JSON copy a fifth larger instead), lists a chat it already listed in the same session as its id and the hits it had not shown, and has a shorter definition. `memory_search` returns each note as its id, one rule line (the title and each rule without its reason) and its date; `read_note` has the full note. On the 0.6.1 agent evals this cut recall's own tokens per task by 13 to 16% with accuracy unchanged.
