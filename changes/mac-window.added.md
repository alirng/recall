**The recall window.** Open recall (⌘O) in the menu bar app opens one window with two views. Memory has the notes list with category tags, filters, a project picker with pins and sort, and a reader with each note's rules, the chats it was learned from, related notes and its history. This Mac has counts, sources, last night's memory run as a waterfall, storage, model and schedule, coordination rules and access. Chats (messages shown as light markdown, with find in chat), Projects and Now are plain lists, and ⌘K opens a palette that searches notes and chats and goes to any view. Sections switch on the next frame, lists move with the arrow keys, and menus are themed with number keys. The window reads everything through `recall api`, starts it when it isn't running, and updates live from its event stream, with no polling. Its only file is `~/.agents/recall/app.json`. The menu bar's Show changes diffs move from `~/Library/Caches/recall` to `~/.agents/recall/cache/diffs`, and the plain-menu setting moves from `defaults` to `"ui": "menu"` in that file. The app has its own icon. Editing and forgetting notes come later.
