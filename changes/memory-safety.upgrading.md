**The notes folder's git history still holds the start of every note's body.** Earlier releases kept it in the deletion ledger, `.recall/notes.json`, which each memory run commits. The first memory run on this release rewrites the ledger without bodies; once it has (no note text left in that file), this removes the old versions from every commit, needs git-filter-repo, and removes the folder's git remote, so add it back if you sync the notes: `cd ~/.agents/memory && git add -A && git commit -q --allow-empty -m "Before purging the ledger's history" && cp .recall/notes.json ../recall/notes-ledger.json && git filter-repo --force --invert-paths --path .recall/notes.json && mkdir -p .recall && mv ../recall/notes-ledger.json .recall/notes.json && git add -A && git commit -qm "Deletion ledger without note bodies"`.
