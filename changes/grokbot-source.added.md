**Grok Bot chats (opt-in).** `recall setup` asks, with a default of no, whether to read the chat cache Grok Bot (Cursor's personal-agent app) keeps on the Mac. Yes reads it read-only, as one chat per bot per day, so a bot's older messages stay in recall's archive as the app's 200-entry window slides; skips the bots you name; and puts the app's folder in your `personal` context, so sessions in other contexts are never handed these chats. `recall dream` leaves them out until you set `[roots.grokbot] mine = true`. `recall search`, `recent`, `show` and `memory search` take `--context NAME`, which limits what comes back to one context from any folder, for an agent such as a Grok Bot that must see only that part of your life. More in docs/grok-bot.md.
