**Grok Bot chats (prototype).** recall reads the transcript cache Grok Bot (Cursor's personal-agent app) keeps on the Mac, read-only, as one chat per bot per day, so a bot's older messages stay in recall's archive as the app's 200-entry window slides. Bots you name in `[grokbot] skip` in config.toml are never read. The chats have no project folder: list the app's folder (`~/Library/Application Support/Grok Bot`) under the context you want them in (for example `personal`) in `[contexts]`, and sessions in other contexts are never handed them. `recall dream` leaves them out until you set `[roots.grokbot] mine = true`.
