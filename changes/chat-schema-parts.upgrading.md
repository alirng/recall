**The chat index rebuilds itself once more.** The chat schema is no longer one number every parser change bumps (it was 7): each module that shapes the index declares its own `CHAT_SCHEMA` string, and the schema is a hash of them all, shown as `p-` and ten hex digits. The first index run after upgrading re-reads your chats; chats whose files are gone come back from the archive. Later rebuilds happen only when a release changes one of those strings.
