**Leaner tool results, off by default.** Seven switches make the three largest tool outputs smaller so that each can be measured on its own: `search-adaptive` (`search_chats` lists three chats instead of eight when the first clearly outscores the second), `search-repeats` (a chat the session was already shown comes back as its id and any new hits), `search-text` (`search_chats` answers in text only, which every agent reads), `search-description` (a shorter `search_chats` definition), `read-window` (`read_chat` with a query or offset and no `limit` shows 12 messages, with a line saying how many lie before and after), `memory-lines` (`memory_search` returns each note as a rule line, id and date, and `read_note` has the rest) and `memory-five` (`memory_search` returns 5 notes when no `limit` is given). Turn them on with `[tools] lean = ["read-window", ...]` in config.toml or `RECALL_LEAN=read-window,...` (`all` for every one). With none on, every tool and its definition are exactly as before.
