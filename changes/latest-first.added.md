**Latest first.** `search_chats` and `read_chat` now say when a later chat in the same project covers the same ground as a chat they return, with its id and date, so an agent asked "what did we decide?" can tell it has opened an older version. Each matching line in search results says who wrote it (you, the agent, or the parent agent that briefed a subagent), and a first `read_chat` of a long chat adds where it ended up and the turns where you changed course. All of it is read from the index with no model call; a search costs about 150 tokens and 60 ms more. Claude Code, Codex and Cursor get the same fields, Cursor in the text form of the results.
