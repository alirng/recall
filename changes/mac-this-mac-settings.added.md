**Change settings on This Mac.** The model that writes notes is a menu of what already works on this Mac (the current model, a signed-in Claude or ChatGPT plan, a running local model, an API provider whose key recall stored); picking one makes one short test call and saves only if it answers. Adding a key or a new provider stays `recall model` in Terminal, so the app never handles a key. Coordination rules save as you change them, with a preset menu and Back to Recommended. Remove old copies lists each copy recall kept before an upgrade with its size and removes only those. The schedule stays read-only, and against a `recall api` from before these writes so do the rest.
