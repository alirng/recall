**Every subagent starts with a brief.** When an agent starts a subagent of any type, recall hands it about 1,000 tokens that bear on its task. The brief holds the project's rules in force, the two or three earlier chats that best match the task (subagents' own reports included, each a dated window with the files it edited, the checks it ran and the commits it made) and open threads. A subagent otherwise starts with none of the session's memory, and Claude Code's Explore and Plan also skip CLAUDE.md. Claude Code and Cursor get it in the subagent's prompt. Codex gets it through `SubagentStart`, which comes with Codex's other hooks and needs `recall install` and a trust in `/hooks`. `recall brief "<task>"` prints one. Each delivery logs which rules went in, by id and version. `[brief] subagents = false` in config.toml turns it off.
