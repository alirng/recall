**Tool calls no longer rescan Cursor's database every 30 minutes.** Cursor's older chats, and its subagent and side chats, sit in a database of several GB, so recall now reads it in full on the first index (in the background, at low priority, stopped after 15 minutes), in the nightly run and on `recall index`, and skips it while the database is unchanged. Other chats are still read as soon as they change. A new Cursor side chat becomes searchable after the next nightly run or `recall index`.
