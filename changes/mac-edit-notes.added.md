**Edit and forget notes in the recall window.** Edit note (⌘E) turns the reader into one text box holding the note's rules, one per line, and shows what saving records as you type: each rule kept, reworded, removed or new. A removed rule isn't learned again from the same chats, and a new one is marked as said by you. Save (⌘S) commits the note, rewrites the MEMORY.md indexes and refreshes search, so agents see it from their next session; History shows "Edited by you". Forget… (or ⌫ in the list) deletes the note after a sheet that says what happens, and Undo (⌘Z) puts it back for 10 seconds. While a memory run is writing notes, Save and Forget wait for it and then go ahead; a note whose file changed since you opened it is never overwritten. Against a `recall api` from before these writes the buttons show read-only with "Update recall to change this here".
