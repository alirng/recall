**Menu bar:** the panel now reads `recall api` when it opens and holds its event stream only while it is open, so it updates live, and a server it started exits 30 seconds after the panel closes. The icon's 15-minute check uses the API only when a server is already running and otherwise runs `recall status --json`, because starting a server for it costs more. With a recall that has no `recall api` (0.5.2 and earlier), the menu bar uses `recall status --json` for everything, as before. `/v1/status` takes `?fresh=1` to skip its 15-second cache.
