**`recall remember "<rule>"` saves a rule you state, at once.** It goes straight into the notes as a note of its own, for the current project, or with `--global` for every project in the folder's `[contexts]` context (a work rule never loads in personal folders), and the next session starts with it. Agents run it through the `recall` skill when you type `/recall remember <rule>` (Claude Code, Cursor) or `$recall remember <rule>` (Codex); the MCP tools stay read-only. A rule is marked `said_by: developer` only when you typed it at your own terminal, or the agent's `--quote` is found in your latest message in that chat's own transcript. Anything else an agent saves is its candidate, which no session is shown unasked, and an agent cannot save a rule with a command, a URL or a destructive step at all. The nightly run keeps your words: it retires the older rules a remembered rule replaces and folds in duplicates, and only a later chat in which you typed something else changes it, never an older chat or the agent. `recall eval memory` gains a `gold` column for this, scored without a judge on cases that remember rules between chats.
