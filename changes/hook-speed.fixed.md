**recall's hooks and tools answer faster.** On a history of 1,200 chats, the edit hook took 80 ms, 180 ms while other chats were working, and about 0.8 s with its cache gone, because before every edit it listed every agent's transcripts and read again in full each chat that had moved in the last 12 hours. Now it reads only what each recent transcript gained since the last edit, and reads chats in full and asks git only when another chat touched the same file: 40 ms, and 150 ms cold. When another chat does have the file open, the git calls run side by side and skip macOS's `/usr/bin/git` stub (380 ms down to 90 ms). A chat without recall's hooks (Codex before you trust them) that starts or resumes is now seen by other chats' edit hooks within five minutes rather than at their next edit. A prompt no longer waits on an Ollama model that is not loaded: asking one started a load that Ollama dropped when the hook gave up, so every prompt waited a quarter of a second and the model never warmed up. Now a background process loads it for the next prompts (at most every two minutes), and a loaded model is waited for at most 100 ms rather than 250 (330 ms down to 100 ms with the model cold). Hooks that do not read the index load 15 ms less code (the turn-end hook: 51 ms down to 36 ms). MCP tool calls read the shell's rc files once per index refresh instead of three times, memory notes load eight times faster (`memory_search` 520 ms down to 160 ms), and a refresh still running after a second, such as the rebuild after an update, carries on in the background while calls answer from the index as it stands and say that chats may be missing.
