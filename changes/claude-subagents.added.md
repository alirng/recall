**Claude Code subagents are searchable.** recall indexes each subagent's transcript as its own chat: the brief its parent agent wrote and the report it sent back, a workflow subagent's structured result included. Like Codex and Cursor subagents, they are never mined for memory. `recall forget` on a Claude Code chat forgets its subagents too, and an index run skips the subagents of a chat already forgotten. In search, a subagent takes a place above another chat only by matching better, and each further subagent of the same parent chat counts for half, so one workflow's dozens of subagents do not fill the results; `recent_chats` leaves subagents out.
