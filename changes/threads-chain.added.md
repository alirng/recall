**Next-hop references.** `search_chats` and `read_chat` results now carry a few references, each an id, a date and one line, so an agent can follow a decision from chat to chat instead of searching again. A search names chats ranked just below its results that cover the same ground as one of them; a `read_chat` names chats on the same ground, the chats just before and after it in the same project, the notes it fed, its commits and other chats that edited the same files. No model call; about 100 tokens per search and 120 per read. Claude Code, Codex and Cursor get the same `refs`, Cursor as `→` lines in the text form of search results.
