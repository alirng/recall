**Codex now asks before `message_chat` runs.** `message_chat` writes a message to another chat's mailbox, and Codex's default `auto` approval let it through without asking, because the tool is marked neither destructive nor open-world. Run `recall install` to add the approval to your existing Codex entry; an approval you set yourself is left alone, and `recall uninstall` removes it with the entry.
