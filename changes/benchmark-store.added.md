**Benchmark figures live in one store.** Every figure in the README, `docs/benchmarks.md` and on rererecall.com, and every other system's figure they compare against, is a row of `docs/benchmarks/results.jsonl`: a benchmark and metric from `docs/benchmarks/registry.json`, the value with its interval, repeats and date, the code it measured (release, commit and product-code hash), the model, judge, harness and conditions, and the run folders it came from. Rows are appended and never edited. `uv run python docs/benchmarks/store.py record RUN_DIR` turns a finished run into rows, and `check` validates the store in CI. The charts draw from the store through `docs/benchmarks/charts.json`, and `docs/benchmarks/figures.json` replaces `results.json` for anyone drawing the same figures. See `docs/benchmarks/README.md`.
