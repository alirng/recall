**Agent eval grading takes the majority of three votes.** `recall eval agent --v2` now grades each reply three times and the majority decides, because one judge call flipped about 3 of 8 verdicts when asked again. Results record `judge_version` as `qa-judge-v2+maj3`, so they never compare with single-vote scores; `--judge-votes 1` is the old judge. `longmemeval --qa` takes the same flag (default 1), and `eval agent --v2 --rejudge RUN_DIR --out FILE` grades the stored replies of an earlier run again without running any agent.
