# Code of conduct

recall follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the
work. Harassment and personal attacks are not tolerated.

To report a problem, contact the maintainer privately through
[a security advisory](https://github.com/alirng/recall/security/advisories/new) (it is
private to maintainers) or via the contact details on the maintainer's GitHub profile.
Reports are handled confidentially.
